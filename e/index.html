Tips agar deployment berhasil

  • • Pastikan nama project minimal 3 karakter dan hanya mengandung huruf kecil, angka, dan tanda hubung.
  • • File HTML harus valid dan memiliki struktur yang benar.
  • • Jika menggunakan ZIP, pastikan file index.html berada di root ZIP, bukan di dalam folder.
  • • Ukuran file tidak boleh melebihi batas yang ditentukan.

Troubleshooting

  • • Jika deployment gagal, periksa kembali nama project dan format file.
  • • Jika URL tidak dapat dibuka, tunggu beberapa saat atau coba deploy ulang.
  • • Pastikan koneksi internet stabil selama proses deployment.
