Tips agar deployment berhasil

  • • Pastikan nama project minimal 3 karakter dan hanya mengandung huruf kecil, angka, dan tanda hubung.
  • • File HTML harus valid dan memiliki struktur yang benar.
  • • Jika menggunakan ZIP, pastikan file index.html berada di root ZIP, bukan di dalam folder.
  • • Ukuran file tidak boleh melebihi batas yang ditentukan.

Troubleshooting

  • • Jika deployment gagal, periksa kembali nama project dan format file.
  • • Jika URL tidak dapat dibuka, tunggu beberapa saat atau coba deploy ulang.
  • • Pastikan koneksi internet stabil selama proses deployment.

FAQ

Ekk Store Deployment Platform adalah layanan untuk men-deploy file HTML atau ZIP menjadi website yang dapat diakses publik secara gratis.

Anda dapat men-deploy website statis berupa file HTML atau file ZIP yang berisi HTML, CSS, JavaScript, dan aset lainnya.

Format yang didukung adalah file .html dan .zip. File ZIP harus berisi file index.html di root arsip.

Masukkan nama project di halaman Deploy, upload file HTML atau ZIP, lalu klik tombol Deploy Sekarang.

Nama project minimal 3 karakter, hanya boleh mengandung huruf kecil (a-z), angka (0-9), dan tanda hubung (-). Harus diawali dan diakhiri huruf kecil atau angka. Tidak boleh ada dua tanda hubung berurutan (--).

Proses deployment biasanya memakan waktu beberapa detik hingga satu menit tergantung ukuran file dan kondisi server.

Status "Sedang deploy" berarti file Anda sedang diproses dan dikirim ke server. Tunggu hingga proses selesai.

"Berhasil" berarti project Anda telah berhasil di-deploy dan dapat diakses melalui URL yang diberikan.

Periksa kembali nama project (minimal 3 karakter, format benar) dan pastikan file valid. Coba lagi setelah beberapa saat.

URL project ditampilkan di output deploy setelah berhasil, dan juga tersimpan di halaman Riwayat Deploy.

Klik menu "Riwayat" di navigasi utama atau sidebar untuk melihat semua riwayat deployment Anda.

Gunakan kolom pencarian di halaman Riwayat untuk mencari berdasarkan nama project.

Klik ikon tempat sampah pada setiap item riwayat untuk menghapus satu per satu, atau gunakan tombol "Bersihkan Riwayat" untuk menghapus semua riwayat lokal.

Ya, Anda dapat men-deploy ulang project dengan nama yang sama. Project lama akan ditimpa dengan yang baru.

File ZIP akan diekstrak di server dan file index.html di dalamnya akan dijadikan halaman utama website Anda.

Pastikan file HTML Anda valid, tidak ada error JavaScript yang fatal, dan semua resource (CSS, JS, gambar) terhubung dengan benar.

Tunggu beberapa saat karena server mungkin masih memproses. Jika masih tidak bisa, coba deploy ulang atau hubungi Ekk Store.
